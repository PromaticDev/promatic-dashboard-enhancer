Promatic Dashboard

Panel de resumen de flota en tiempo real, integrado como extensión nativa de la plataforma PILOT.

Full UI Extension

Qué hace

La extensión agrega una pestaña propia en el panel de navegación de PILOT con un dashboard de flota. Reúne en una sola vista el estado de conectividad de los vehículos, las alertas relevantes, el kilometraje y otros indicadores operativos, actualizándose en vivo con el árbol de vehículos de la plataforma.

Está pensada para dar una lectura rápida del estado general de la flota sin tener que recorrer los distintos reportes nativos, y para enlazar de vuelta a ellos cuando se necesita el detalle.

Características principales

  • Estado de flota en vivo — vehículos activos, en movimiento y detenidos, en porcentajes sobre el total.
  • Sin Señal GPS — vehículos sin conexión al servidor agrupados por antigüedad de la última señal (menos de 24 h, entre 24 y 48 h, más de 48 h), con realce visual para los casos críticos.
  • Alertas Generales — conteo de accidentes recientes y vehículos que requieren mantención.
  • Vehículos con Kilometraje en Exceso — ranking de kilómetros recorridos en el período configurado, con enlace directo al informe de kilometraje de PILOT.
  • Hora Oficial — reloj con zona horaria configurable.
  • Alcance ajustable — el dashboard puede seguir la selección de vehículos del panel "Principal" de PILOT o considerar la flota completa, desde un control en el propio panel.
  • Actualización manual — botón para refrescar todos los indicadores sin recargar la página.
  • Solo lectura — la extensión únicamente consulta datos; nunca crea, modifica ni elimina información en PILOT.

Configuración — config.json

El comportamiento del dashboard se ajusta desde el archivo config.json incluido en la extensión, sin necesidad de tocar el código. Si el archivo no está disponible, la extensión usa valores por defecto equivalentes. 

{
  "top5km": {
    "windowDays": 7,          // días hacia atrás para el ranking de kilometraje
    "activeVehicleCap": 300,  // tope de vehículos a consultar
    "source": "ratings",      // fuente de datos: "ratings" o "reports"
    "count": 5                // filas visibles en la tarjeta
  },
  "fleet": {
    "scope": "pilot-selection", // "pilot-selection" (sigue la selección) o "all"
    "maxVehicles": 500          // tope de seguridad para llamadas a la API
  },
  "clock": {
    "timeZone": "America/Santiago", // identificador de zona horaria IANA
    "locale": "es-CL",             // formato de hora
    "label": "Hora Oficial"        // rótulo del widget
  }
}
SecciónPara qué sirve
top5kmVentana de tiempo, límites y fuente del ranking de kilometraje.
fleetQué vehículos considera el dashboard y tope de seguridad de consultas.
clockZona horaria, idioma y rótulo del reloj.

Los cambios en config.json se aplican al volver a publicar la extensión. La estructura está preparada para que, más adelante, un servicio externo pueda entregar la misma configuración de forma dinámica.

Instalación

Registrar la URL base de esta extensión en la administración de PILOT. Una vez cargada, aparece una nueva pestaña "Promatic Dashboard" en el panel de navegación izquierdo.
