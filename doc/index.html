Promatic Dashboard

Panel de resumen de flota en tiempo real, integrado como extensión nativa de la plataforma PILOT.

Full UI Extension

Qué hace

La extensión agrega una pestaña propia en el panel de navegación de PILOT con un dashboard de flota. Reúne en una sola vista el estado de conectividad de los vehículos, las alertas relevantes, el kilometraje y otros indicadores operativos, actualizándose en vivo con el árbol de vehículos de la plataforma.

Está pensada para dar una lectura rápida del estado general de la flota sin tener que recorrer los distintos reportes nativos, y para enlazar de vuelta a ellos cuando se necesita el detalle.

Características principales

  • Estado de flota en vivo — vehículos activos, en movimiento y detenidos, en porcentajes sobre el total.
  • Sin Señal GPS — vehículos sin conexión al servidor agrupados por antigüedad de la última señal (menos de 24 h, entre 24 y 48 h, más de 48 h), con realce visual para los casos críticos.
  • Alertas Generales — conteo de accidentes recientes y vehículos que requieren mantención.
  • Vehículos con Kilometraje en Exceso — ranking de kilómetros recorridos en el período configurado, con enlace directo al informe de kilometraje de PILOT.
  • Hora Oficial — reloj con zona horaria configurable.
  • Alcance ajustable — el dashboard puede seguir la selección de vehículos del panel "Principal" de PILOT o considerar la flota completa, desde un control en el propio panel.
  • Actualización manual — botón para refrescar todos los indicadores sin recargar la página.
  • Solo lectura — la extensión únicamente consulta datos; nunca crea, modifica ni elimina información en PILOT.

Configuración — config.json

El comportamiento del dashboard se ajusta desde el archivo config.json incluido en la extensión, sin necesidad de tocar el código. Si el archivo no está disponible, la extensión usa valores por defecto equivalentes. 

{
  "top5km": {
    "windowDays": 7,          // días hacia atrás para el ranking de kilometraje
    "activeVehicleCap": 300,  // tope de vehículos a consultar
    "source": "ratings",      // fuente de datos: "ratings" o "reports"
    "count": 5                // filas visibles en la tarjeta
  },
  "fleet": {
    "scope": "pilot-selection", // "pilot-selection" (sigue la selección) o "all"
    "maxVehicles": 500          // tope de seguridad para llamadas a la API
  },
  "clock": {
    "timeZone": "America/Santiago", // identificador de zona horaria IANA
    "locale": "es-CL",              // formato de hora
    "label": "Hora Oficial"        // rótulo del widget
  }
}
SecciónPara qué sirve
top5kmVentana de tiempo, límites y fuente del ranking de kilometraje.
fleetQué vehículos considera el dashboard y tope de seguridad de consultas.
clockZona horaria, idioma y rótulo del reloj.

Los cambios en config.json se aplican al volver a publicar la extensión. La estructura está preparada para que, más adelante, un servicio externo pueda entregar la misma configuración de forma dinámica.

Instalación

Registrar la URL base de esta extensión en la administración de PILOT. Una vez cargada, aparece una nueva pestaña "Promatic Dashboard" en el panel de navegación izquierdo.

Estado

Versión 0.5.0 — en desarrollo activo, verificada y funcionando en instancia PILOT real.

Promatic Dashboard

Real-time fleet overview dashboard, integrated as a native extension of the PILOT platform.

Full UI Extension

What it does

The extension adds its own tab to the PILOT navigation panel with a fleet dashboard. It gathers vehicle connectivity status, relevant alerts, mileage, and other operational indicators into a single view, updating live with the platform's vehicle tree.

It is designed to provide a quick read of the overall fleet status without having to navigate through various native reports, while offering direct links back to them when detailed information is needed.

Key Features

  • Live Fleet Status — active, moving, and stopped vehicles, displayed as percentages of the total.
  • No GPS Signal — vehicles disconnected from the server grouped by age of the last signal (less than 24h, between 24 and 48h, over 48h), featuring visual highlighting for critical cases.
  • General Alerts — count of recent accidents and vehicles requiring maintenance.
  • Excess Mileage Vehicles — ranking of distance driven during the configured timeframe, with a direct link to the PILOT mileage report.
  • Official Time — clock with configurable timezone.
  • Adjustable Scope — the dashboard can follow the vehicle selection from the PILOT "Main" panel or evaluate the entire fleet, toggled via a control directly on the dashboard.
  • Manual Refresh — button to refresh all indicators without reloading the page.
  • Read-Only — the extension only queries data; it never creates, modifies, or deletes information in PILOT.

Configuration — config.json

Dashboard behavior is adjusted via the config.json file included in the extension, without touching any code. If the file is not available, the extension falls back to equivalent default values. 

{
  "top5km": {
    "windowDays": 7,          // days back for mileage ranking
    "activeVehicleCap": 300,  // maximum vehicles to query
    "source": "ratings",      // data source: "ratings" or "reports"
    "count": 5                // visible rows in card
  },
  "fleet": {
    "scope": "pilot-selection", // "pilot-selection" (follows selection) or "all"
    "maxVehicles": 500          // safety cap for API calls
  },
  "clock": {
    "timeZone": "America/Santiago", // IANA time zone identifier
    "locale": "es-CL",              // time format locale
    "label": "Official Time"        // widget label
  }
}
SectionDescription
top5kmTime window, limits, and data source for the mileage ranking.
fleetWhich vehicles the dashboard considers and safety query cap.
clockTime zone, language locale, and clock label.

Changes to config.json take effect upon re-publishing the extension. The structure is prepared so that an external service can dynamically deliver the same configuration in the future.

Installation

Register the base URL of this extension in the PILOT administration panel. Once loaded, a new tab named "Promatic Dashboard" will appear in the left navigation panel.

Status

Version 0.5.0 — under active development, verified and running on a live PILOT instance.
